01 / 模型里有什么

一位用户，一部电影，怎么算分？

教学例子 · 3 维

点击表格中的行，选择要配对的用户和电影。每一行就是一个 embedding：用一串数字表示一个人或一部电影。真实实验每行有 16 个数字，这里缩成 3 个。

一条教学训练记录：user_id = 0，item_id = 2，评分 = 5
它对应用户表 ID 0 的一行和电影表 ID 2 的一行。

特别看这里

给某一位用户的所有电影都加同一个数，只会改变分数，不会改变这位用户的电影排序。你可以选择“用户基础分”或“全局基础分”亲手验证。

本轮只比较两种结果

BP 训练完成后，
Astra 还能改进多少？

① BP 训练→② Astra 看权重＋训练集→直接修改权重

两者从同一个 BP 模型出发。Astra 能看到全部参数和训练交互，也明确知道每个 user / item ID 对应 embedding 表的哪一行。

Astra 可分析训练集预测与误差，并进行一次性解析更新；不再进行 BP 或迭代训练。验证、测试数据不交给它，不提供改进方向假设。主比较不再包含盲编辑或文本条件。

item ID 与 embedding 如何对应？

训练记录里的 item_id = 17，就直接读取电影 embedding 表的第 17 行（从 0 开始计数），以及电影基础分表的第 17 行。用户 ID 的对应方式相同。这一映射会明确交给 Astra。
