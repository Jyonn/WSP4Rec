一、电影简介与 Llama-3 表示

从公开的 mt0rm0/movie_descriptors 数据集取得真实电影 overview。
数据来源于 TMDB 元数据的整理版，固定源版本和文件哈希。
按电影名称、别名和发行年份做保守匹配，不自动接受模糊匹配，也不生成剧情。
1,682 部电影中匹配 1,570 部（93.3%）；112 部缺失或有歧义，显式保留标记。
101 部采用唯一名称匹配且年份相差一年，其身份匹配仍值得后续抽查。

编码器是服务器已缓存的 meta-llama/Meta-Llama-3-8B，固定版本
8cde5ca8380496c9a6cc7ef3a8b46a0372a1d920。
它是冻结的基础语言模型，不是专门训练的 embedding 模型，没有微调、生成描述或生成回答。

实际拼接模板：
Represent the following movie for personalized recommendation based on its plot, themes, genre, mood, and setting. Use only the supplied movie information.
Title: {原始 MovieLens 标题，保留年份}
Description: {检索匹配到的真实简介}
Movie representation:

仅标题对照使用同一个模型、同一指令与结尾，只去掉 Description 行。
从最后一层、最后一个有效输入 token 读取 4,096 维表示，再进行 L2 归一化。
显式设置有效 token 的位置编号，不让位置编号依赖左侧填充长度。
输入上限 512 token，只截断 description；本轮实际没有发生截断。
缺失简介的 112 部电影最终直接复用对应的仅标题向量，并提供 availability mask。

两套向量均为 1,682 × 4,096，原始文件在 runs/followup/llama3/。
已验证输入和向量哈希、维度、数值有限、单位长度及缺失回退完全一致。
最终提取用一张 A100，47.62 秒，峰值已分配 GPU 显存 15.54 GB。
此前一次完整提取保留为数值检查版本，59.33 秒；两次合计 106.95 秒。
另有一次模型载入前的 CUDA 计数初始化失败，未测得耗时，记录在执行日志中。
这些是进程内计时，不包含准备、下载和传输，也不等于货币费用。

简介并非均匀覆盖：零训练交互物品为 76.1%，低支持为 88.8%，中支持为 96.7%，高支持为 97.2%。
未来评价冷热门差异时必须区分 description 是否存在，避免把覆盖率差异误当成方法差异。
随机电影对的平均余弦相似度约为 0.94（仅标题）和 0.93（加简介），向量方向较集中。
因此，成功提取表示不等于已经证明语义表示或推荐效果更好，仍需要验证池化、公共指令成分及实际推荐效果。
本轮没有再读取推荐测试标签或报告新的推荐分数；旧研究的冻结输入哈希保持一致。

二、Astra 编辑动机的可观察时间线

输入阶段：实验接口已经展示物品偏置乘 0.5、popularity_shift(-0.1)、训练计数和支持度分组。
父代理提示也提过 bias 校准方向，因此实验存在设计者的先验引导。

首轮反馈之前：八条轨迹的第一批提案中已经出现 bias 或支持度假设。
BPR 权重可见编辑器记录了物品偏置与 log(训练计数) 的相关性约 0.905，
以及物品向量范数与 log(训练计数) 的相关性约 0.913，并提出偏置减半等并行候选。
这表明动机并非首次候选的验证结果出现后才补写，但不能证明私有内部思考的精确先后顺序。

反馈阶段：BPR 偏置减半把验证 NDCG@10 从 0.119012 提到 0.121473；
另一种压低流行度相关向量维度的候选反而降到 0.114528。
第二轮进一步围绕偏置缩放搜索方向与强度。
最后八条轨迹中，六条选择第二轮提案，两条保留第一轮最佳。

MSE 的四条轨迹在首轮就尝试正向支持度先验，最终也都增加这一先验。
所以，“编辑围绕 bias 展开”不等于“编辑在减少流行度偏差”。
学习到的 item bias 也不等于训练频次，相关性高不能直接证明二者等同。
排序指标改善本身不是消除 popularity bias 的证据。

目前最准确的解释：在设计者给出的方向与操作接口下，Astra 事前提出假设，再由反馈筛选。
下一轮若要研究自主发现，应去掉 bias/popularity 的定向例子，先保存简短且可检验的假设，
再提供验证反馈，并独立测量曝光分布与长尾召回，而不只看总体排序指标。
这里审计的是保存的显式 rationale 和诊断，不推断或索取不可见的内部思维链。

详细证据：astra_motivation_audit.json、description_coverage.json、
llama3_embedding_metadata.json、llama3_quality_checks.json、execution_attempts.json。
